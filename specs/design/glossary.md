# Glossary

Shared language for all design specs. Each term is defined once here; other specs use the term exactly as written and link here instead of redefining it. Rules: [`design.md`](design.md#rules-for-every-design-spec).

## Conventions

- One term per concept: no synonyms. Pick one word and use it everywhere.
- One meaning per term. If a common genre term means something specific here, define this game's meaning.
- Characters and entities get a one-line entry pointing to their own spec in [`characters/`](characters/) or [`entities/`](entities/).
- Keep rows alphabetical.
