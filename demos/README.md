# `demos/`

Gameplay demos: one folder per demo, each a reference artifact kept apart from the main code. Main code never imports from here.

Each demo expresses the game's style and uses only reviewed assets from the asset pipeline; no ad hoc placeholders.

Contract: [`docs/demos.md`](../docs/demos.md) and [`docs/demo-style-assets.md`](../docs/demo-style-assets.md). Build one with the `create-gameplay-demo` skill.
